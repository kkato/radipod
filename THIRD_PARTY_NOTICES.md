# Protocol reference

The radiko HTML5 authentication, stream discovery, and time-free chunk request
parameters were implemented with reference to
[uru2/rec_radiko_ts](https://github.com/uru2/rec_radiko_ts).
Radipod does not execute or bundle that shell script.
